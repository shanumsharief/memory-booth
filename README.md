# Memory Booth ✦

A tiny photo booth that runs in your browser. Take four photos, pick a sticker, and keep the strip.



## What it does

- **Four-photo strip.** Allow camera access, hit the shutter, and get a finished strip.
- **Stickers.** Choose a star, heart, flower or postal stamp, or none.
- **Download.** Save the strip as an image.
- **Print sheet.** Lay out strips on one page (one-up, two-up or classic four-up), ready to trim.
- **Shutter sound.** A small click on each shot, which you can turn off.
- **The album.** A scrapbook-style section of sample memories.

## Privacy

The camera feed is processed in the browser. There are no accounts and no uploads.

## Tech stack

Css

## Run locally

```bash
git clone https://github.com/shanumsharief/memory-booth.git
cd memory-booth
npm install
npm run dev
```

Open the local URL and allow camera access. Browsers only allow camera access on `localhost` or HTTPS.
